1 Distribución Uniforme Continua

Ejercicio 1.1 (Tiempo de carga entre 2 y 8 segundos)

Code

El modelo uniforme continuo permitió calcular probabilidades acumuladas e intervalos de tiempo con facilidad. La simulación de 1,000 tiempos de carga coincidió de forma exacta con la densidad teórica esperada.

Ejercicio 1.2 (TCL con Distribución Asimétrica/Truncada)

Code 
set.seed(123)
n_mues <- c(5, 15, 30, 60, 120)
par(mfrow = c(2, 3))

for (n in n_mues) {
  medias <- replicate(800, {
    datos <- runif(100, 0, 1)
    mean(datos[datos > 0.3]) # Truncada para generar sesgo
  })
  hist(medias, probability = TRUE, col = "thistle", main = paste("n =", n), xlab = "Medias")
}
par(mfrow = c(1, 1))

Se observó que, a pesar de recortar la distribución original e introducir un sesgo asimétrico, la distribución de las medias muestrales se vuelve progresivamente simétrica y normal a medida que \(n\) aumenta, verificando el TCL.

Ejercicio 3.2 (Suma de Exponenciales \(\to\) Gamma)

Code 
set.seed(123)
rate_exp <- 1.5

for (n_exp in c(5, 10, 20)) {
  mat_exp <- matrix(rexp(1000 * n_exp, rate = rate_exp), ncol = n_exp)
  sumas_exp <- rowSums(mat_exp)
  
  hist(sumas_exp, probability = TRUE, main = paste("Suma de", n_exp, "exponenciales"), col = "plum")
  curve(dgamma(x, shape = n_exp, rate = rate_exp), add = TRUE, col = "purple", lwd = 2)
}

Se verificó la propiedad teórica de que la suma de \(n\) variables exponenciales independientes con parámetro \(\lambda\) da como resultado exacto una variable Gamma de parámetros \((n, \lambda)\).

6 Distribución Ji-cuadrada

Ejercicios 6.1 a 6.5 (Convergencia, TCL, Aditividad y Relación con Normal)

Code 
set.seed(123)
# Ejercicio 6.3: Suma de normales al cuadrado -> Ji-cuadrada
df <- 10; n_sim <- 10000
mat_norm <- matrix(rnorm(n_sim * df), ncol = df)
ji_sim <- rowSums(mat_norm^2)

cat("Media Ji-cuadrada teórica:", df, "| Simulada:", mean(ji_sim), "\n")

Code 
# Ejercicio 6.5: Aditividad Ji1 + Ji2
j1 <- rchisq(n_sim, df = 5)
j2 <- rchisq(n_sim, df = 15)
suma_j <- j1 + j2 # Debería ser Ji-cuadrada con df = 20

Media de la suma: 20.08132 | Esperada: 20

Quedó demostrada la propiedad aditiva de la Ji-cuadrada (\(\chi^2_{n} + \chi^2_{m} = \chi^2_{n+m}\)) y su origen estocástico a partir del cuadrado de variables normales estándar independientes.

8 Distribución F de Fisher

Ejercicio 8.1 (Propiedades y Verificación)

Code 
set.seed(123)
# a. Si X ~ t(n) -> X^2 ~ F(1, n)
X_t <- rt(10000, df = 10)
F_de_t <- X_t^2

# b. Si X ~ F(a, b) -> 1/X ~ F(b, a)
X_f <- rf(10000, df1 = 5, df2 = 10)
inv_f <- 1 / X_f

# c. Cociente de Ji-cuadradas: (X/a) / (Y/b) ~ F(a, b)
chi_a <- rchisq(10000, df = 5) / 5
chi_b <- rchisq(10000, df = 10) / 10
F_cociente <- chi_a / chi_b

cat("Media cociente Ji-cuadradas:", mean(F_cociente), "| Teórica 10/8:", 10/8, "\n")
Media cociente Ji-cuadradas: 1.259551 | Teórica 10/8: 1.25

Se verificaron numéricamente las tres propiedades teóricas fundamentales de la distribución F, confirmando su relación con la distribución \(t\) de Student y el cociente de dos Ji-cuadradas independientes.

Implementar estos modelos me permitió comprobar de forma propiedades fundamentales, tales como la relación inversa entre los parámetros de tasa y los tiempos de espera, la flexibilidad de las distribuciones Beta y Weibull para modelar proporciones y confiabilidad industrial, y las construcciones estocásticas que relacionan a la normal con la Ji-cuadrada, la \(t\) y la \(F\).
