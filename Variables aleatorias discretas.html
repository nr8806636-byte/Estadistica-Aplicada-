1 Distribución Uniforme Discreta

1.0.1 Ejercicio 1.1

Simular 500 observaciones de \(X \sim \text{Uniforme}(\{0, 1, 2, 3, 4\})\) y comparar frecuencias observadas vs. teóricas.

Code 
set.seed(123)
n_obs <- 500
valores <- 0:4

# Simulación
muestra_unif <- sample(valores, size = n_obs, replace = TRUE)

# Frecuencias observadas vs teóricas (0.2 * 500 = 100)
tabla_frec <- table(muestra_unif)
tabla_comparativa <- data.frame(
  Valor = valores,
  Frec_Observada = as.numeric(tabla_frec),
  Frec_Teorica = n_obs / length(valores),
  Prob_Observada = as.numeric(tabla_frec) / n_obs,
  Prob_Teorica = 1 / length(valores)
)
print(tabla_comparativa)

2     1            103          100          0.206          0.2

4     3             93          100          0.186          0.2
5     4            100          100          0.200          0.2

En este ejercicio simulé 500 lanzamientos bajo una distribución uniforme discreta y los contrasté con los valores teóricos esperados (100 para cada número). Al revisar los resultados, me di cuenta de que las frecuencias observadas fluctúan un poco alrededor del valor teórico debido al azar de la muestra, pero la proporción se mantiene muy cercana, lo que demuestra empíricamente la equiprobabilidad.

1.0.2 Ejercicio 1.2

Verificar el Teorema Central del Límite (TCL) con \(k = 1000\) muestras de tamaño \(n = 50\) de \(X \sim \text{Uniforme}(\{1, 2, \dots, 10\})\).

Code 
set.seed(123)
k <- 1000
n <- 50
valores_10 <- 1:10

# Medias teóricas
mu_teorica <- mean(valores_10) # 5.5
var_teorica <- sum((valores_10 - mu_teorica)^2) / length(valores_10) # 8.25
se_teorica <- sqrt(var_teorica / n)

# Generación de medias muestrales
medias_unif <- replicate(k, mean(sample(valores_10, size = n, replace = TRUE)))

# Histograma para verificar normalidad
hist(medias_unif, probability = TRUE, main = "TCL - Uniforme Discreta", 
     xlab = "Medias Muestrales", col = "lightblue", border = "white")
curve(dnorm(x, mean = mu_teorica, sd = se_teorica), add = TRUE, col = "red", lwd = 2)

Evalué el comportamiento de 1,000 medias muestrales sacadas de un conjunto uniforme. Concluí que, aunque la variable original no tiene forma de campana, al tomar tamaños de muestra de \(n = 50\), la distribución de las medias se vuelve perfectamente normal de acuerdo con el Teorema Central del Límite.

4 Distribución Binomial Negativa

4.0.1 Ejercicio 4.1

Función que compara la suma de geométricas con la binomial negativa.

Code 
compara_geom_nbinom <- function(r, p, n_sim = 10000) {
  # Suma de r geométricas independientes
  mat_geom <- matrix(rgeom(r * n_sim, prob = p), nrow = n_sim, ncol = r)
  suma_geom <- rowSums(mat_geom)
  
  # Binomial Negativa directa
  directo_nbinom <- rnbinom(n_sim, size = r, prob = p)
  
  # Gráfico comparativo
  par(mfrow = c(1, 2))
  hist(suma_geom, main = "Suma de Geométricas", col = "skyblue", probability = TRUE)
  hist(directo_nbinom, main = "Binomial Negativa Directa", col = "salmon", probability = TRUE)
  par(mfrow = c(1, 1))
}

# Prueba de la función

Creé una función personalizada para contrastar la teoría de que una binomial negativa equivale a sumar varios procesos geométricos independientes. Los histogramas generados lado a lado resultaron ser virtualmente idénticos, validando visualmente la relación matemática.

Code 
# c. Función de costo esperado diario para un nivel de inventario S
costo_esperado <- function(S, lambda = 8, c_mant = 2, c_falt = 15, c_adq = 10) {
  x <- 0:50 # Rango amplio de demanda
  p_x <- dpois(x, lambda = lambda)
  
  unid_no_vendidas <- pmax(0, S - x)
  ventas_perdidas  <- pmax(0, x - S)
  
  costo_diario <- (c_adq * S) + (c_mant * unid_no_vendidas) + (c_falt * ventas_perdidas)
  return(sum(costo_diario * p_x))
}

cat("c. Costo esperado con inventario S = 12:", costo_esperado(12), "\n")

6 Conclusión

El desarrollo de este trabajo permitió integrar de manera teórica y práctica el estudio de las variables aleatorias discretas mediante la programación en R y el uso de simulaciones estocásticas. A través de la implementación de modelos como el Uniforme Discreto, Bernoulli, Binomial, Geométrico, Binomial Negativo y Poisson, fue posible comprobar experimentalmente propiedades fundamentales de la inferencia estadística, tales como la esperanza, la varianza, la propiedad de falta de memoria y los procesos de aditividad entre variables independientes.

Asimismo, la verificación reiterada del Teorema Central del Límite (TCL) demostró cómo los promedios de muestras aleatorias convergen consistentemente hacia una distribución normal, independientemente de la forma o el sesgo de la distribución original. Finalmente, la aplicación de estos conceptos en problemas de optimización real evidenció la enorme utilidad práctica de la modelación matemática para equilibrar costos y tomar decisiones óptimas bajo condiciones de incertidumbre, consolidando un análisis riguroso y completo dentro del campo de la economía industrial y la estadística.
